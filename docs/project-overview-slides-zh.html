02 / MOTIVATION
Problem & Principles

智能体运行不是一条单线日志

  • 01
    来源异构

    不同客户端的事件名、关联 ID 和载荷结构无法直接比较。

  • 02
    工具成对语义缺失

    调用与结果分散，难以看出耗时、状态和失败位置。

  • 03
    子智能体结构隐身

    委派、执行和结果回传混在主线程事件中。

  • 04
    历史无法重演

    静态日志无法回答“当时画面和状态是什么”。

  • 事实与投影分离

    TraceEvent 保留事实，AtomicFlowEvent 表达可视化语义。

  • 本地优先

    回环地址、JSONL 和本地脱敏构成默认隐私边界。

  • 可降级运行

    Hook 失败不阻断 Agent，Worker 失败回退主线程。

  • 稳定跨平台语义

    平台可变，27 个基础原子和 6 个领域保持一致。

10 / ROUTING
Orthogonal Router

路由器如何选出一条清晰的线

端点先从节点端口出发，路径只能水平或垂直；穿过节点的候选直接淘汰，其余候选按长度、折点和交叉数量评分。

01
先满足硬约束

线路保持横平竖直，并与节点、分组标题和画布边界留出安全距离。

02
再比较候选路径

路径越短越好；每增加一个折点都会加分，线路交叉会受到更高惩罚。

03
最后重排冲突边

优先重新计算交叉、重叠或过近的线路，直到没有可优化冲突或达到轮次上限。

避障12 px 折点32 交叉960 线距16 px 轮次32
计算默认在 Web Worker 中执行；Worker 不可用时加载同一算法回退主线程。测试会逐段验证每条可见边只有水平段或垂直段。
